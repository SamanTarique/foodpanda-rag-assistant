# Foodpanda RAG Assistant

A **Retrieval-Augmented Generation (RAG)** chatbot that answers questions about foodpanda Pakistan’s public policies, including FAQs, refunds, delivery, and payments. The project uses **FAISS** for fast vector search and the **Gemini API** for generating helpful, context-aware responses.

## Features

- Answers policy-related questions in natural language
- Retrieves relevant information from indexed documents using FAISS
- Generates responses with Gemini API
- Focused on foodpanda Pakistan public policies
- Lightweight Python-based implementation

## Tech Stack

- **Python**
- **FAISS**
- **Gemini API**
- **RAG architecture**

## How It Works

1. Public policy documents are collected and prepared.
2. Text is embedded and stored in a FAISS index.
3. When a user asks a question, the system retrieves the most relevant policy chunks.
4. Gemini uses the retrieved context to generate an accurate answer.
